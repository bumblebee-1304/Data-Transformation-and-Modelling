Data Transformation and Modelling Using Power Query

1. Data Transformation  

**Power Query was used to transform the raw dataset into a structured and analysis-ready format.**

- Data Import: Imported the source dataset into Power Query for transformation.
- Data Cleaning: Reviewed the dataset to identify and handle missing values, inconsistencies, and unwanted data.
- Data Type Conversion: Changed column data types to ensure accurate calculations and analysis.
- Custom Columns: Created new columns using custom formulas to derive additional information from existing fields.
- Data Formatting: Standardized relevant columns to improve data consistency and readability.
- Data Validation: Reviewed the transformed data to ensure accuracy and suitability for further analysis.

2. Data Modelling  

**Data modelling was performed to organize the transformed data and prepare it for reporting and analysis.**

- Data Structure: Reviewed the table structure and column relationships to support efficient analysis.
- Calculated Fields: Prepared relevant fields for business calculations and performance analysis.
- Data Preparation: Ensured that the transformed dataset was suitable for use in Power BI reports and visualizations.
- Model Readiness: Organized the data to support meaningful comparisons, calculations, and insights.

3. Outcome  

The transformation and modelling process improved data consistency, structure, and usability. The resulting dataset was prepared for further analysis and visualization in Power BI.
